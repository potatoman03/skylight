A browser that feels like your Mac.

Skylight is a free, open-source browser with Spaces and a vertical sidebar, built around Chromium.

Download for Mac View the source

macOS 26 or later, Apple silicon

Built for a lot of tabs

Spaces, each with its own logins
Give a Space its own profile and it keeps its own cookies, passwords and extension data. Work and personal stay apart.
A sidebar that tidies itself
Favorites and pinned tabs stay put. Today's tabs archive themselves after 12 hours, and pages you've left go to sleep.
Your Chrome extensions
Install extensions from the Chrome Web Store. Everything runs on Chromium, so sites work the way you expect.
Themes worth keeping
Quiet colors, live patterns or whole scenes. Drop in a picture and Skylight builds a theme around it.
Bring everything with you
Import tabs, bookmarks, passwords and sign-ins from Aside, Arc, Chrome, Dia, Brave, Edge and other Chromium browsers.
Open to your AI agents
A built-in MCP server lets agents use the browser, and asks you first before they change anything.

Installing Skylight

  1. Open Skylight.dmg and drag Skylight into Applications.
  2. Open Skylight. macOS will say it can't check the app, because it isn't notarized by Apple yet.
  3. Go to System Settings, then Privacy & Security, and choose Open Anyway. You only do this once.

After that, Skylight updates itself. It's all on GitHub if you'd rather read the code or build it yourself.
